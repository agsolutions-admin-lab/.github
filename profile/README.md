# AG Solutions Admin Lab

Welcome to the AG Solutions GitHub organization.

## Purpose

This is a practice organization for learning GitHub administration,
access control, repository management, and security.

## GitHub Administration

The GitHub administrator is responsible for managing organization
settings, repositories, teams, permissions, and security.

## Access Requests

Users who need access to a repository should submit an access request
with the repository name, required permission, and business reason.

Owner
  → Organization administrator
  → Manages settings, members, teams, repositories, etc.

Member
  → Normal organization user
  → Gets access according to assigned permissions/teams

Billing Manager
  → Handles billing-related responsibilities
  → Does not need to be an organization Owner
